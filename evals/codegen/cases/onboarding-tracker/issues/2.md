> **Rationale:** Delivers the staff-facing SPA screens for the dashboard, onboarding records, department task queues, and template management.

## Scope

Implement the onboarding-webapp SPA per `specs/design/components/onboarding-webapp/design.json`, driving all data from onboarding-api, using the screens defined in `wireframes.dsl`.

Screens: Dashboard, NewOnboarding, OnboardingDetail, AddTask, ItTasks, FacilitiesTasks, HrTasks, TaskTemplates, EditTemplate

Flows:

- [ ] **F1 · Manage onboarding**
  Create onboarding records, handle exceptions, watch the dashboard, close out onboarding
  Persona: HR Coordinator
  Stories: 1, 2, 3, 4, 9, 11
  Walk: Dashboard → NewOnboarding → OnboardingDetail → AddTask → HrTasks
- [ ] **F2 · IT task queue**
  Work through IT's onboarding tasks across all new hires
  Persona: IT Staff
  Stories: 5, 6, 10
  Walk: ItTasks
- [ ] **F3 · Facilities task queue**
  Work through Facilities' onboarding tasks across all new hires
  Persona: Facilities Staff
  Stories: 7, 8, 10
  Walk: FacilitiesTasks
- [ ] **F4 · Template management**
  Keep the standard per-department task templates current
  Persona: Admin
  Stories: 12
  Walk: TaskTemplates → EditTemplate

No flow: none — stories 1–12 are all walked above (story 10, overdue flagging, appears on Dashboard/OnboardingDetail/queue tables within F1–F3).

All data reads/writes go through onboarding-api's REST endpoints; sign-in via Thunder SSO (platform-resource, no Task). No file/document upload UI and no notification UI (out of scope per PRD).

## Acceptance

- Every screen in `wireframes.dsl` is built and wired per its elements and navigation targets.
- Each flow's walk is fully navigable end to end for its role, gated per `security.json` roles/grants.
- Overdue tasks are visibly flagged (badge/indicator) on Dashboard, OnboardingDetail, and each department's task queue.
- Onboarding-record completion is blocked in the UI when tasks remain incomplete (mirrors API 400).
- Mock-mode smoke walk of every flow passes per the `mock-verification` skill.
