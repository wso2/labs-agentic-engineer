> **Rationale:** Owns titles and copies; the circulation API builds on it.

## Scope
Implement catalogue-service in Ballerina per specs/design/components/catalogue-service/design.json and openapi.yaml: titles CRUD, search by name/author/subject, copies with status (available, on-loan, on-hold, withdrawn), per-title availableCopies, persisted in Postgres. Provisioning gate: platform resource catalogue-db (postgres-cnpg) — flagged, not a Task. No sign-in handling; intranet only, called by circulation-api.

No flow: backend service, no views (stories 1, 2, 8, 9 are served via the API).

## Acceptance
- All operations in openapi.yaml implemented and conformant (pagination, error shape).
- Deleting a title with conflicting state returns 409.
- bal build && bal test pass.
