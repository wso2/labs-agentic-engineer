# Claims

## Purpose

An employee files an expense claim and follows it to a decision.

## User Stories

- F1.1 As an Employee, I want to submit an expense claim with a description, an amount and a date, so that Finance has a record to act on.
- F1.2 As an Employee, I want to see my own claims and their current status, so that I know what has been decided and what is still waiting.
- F1.3 As an Employee, I want to see the decision and the reason on a claim of mine, so that I do not have to ask anybody what happened to it. Needs: F2.
