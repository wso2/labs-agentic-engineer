# Consolidated order

## Purpose

Once a round closes, the opener gets one order to place and knows who owes what.

Needs: F2.

## User Stories

- F3.1 As the opener, once my round has closed, I see its items grouped by description with total quantities, so I know what to order.
- F3.2 As a teammate, I see each person's items and cost total and the round's grand total, so everyone knows who owes what.
